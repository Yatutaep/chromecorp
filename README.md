# Chrome & Corp (Fabric 1.20.1)

A Minecraft Fabric mod inspired by Cyberpunk 2077, adding cyberware implants, chrome enhancements, and cyberdeck systems to your game.

[Русская версия ниже / Russian version below]

## Installation
1. Install Fabric Loader 0.15.11+ for Minecraft 1.20.1 (fabricmc.net/use/installer)
2. Download Fabric API 0.92.2+1.20.1 and place it in your mods folder
3. Download chromecorp-0.1.0.jar and place it in your mods folder

## Building from Source
- **Via GitHub**: Clone this repository, go to Actions tab → build → download artifact chromecorp-jar
- **Locally**: Requires JDK 17 + Gradle 8.5, run build.bat (Windows) or build.sh (Linux/Mac). JAR will be in build/libs

## Controls
- **V** — Chrono ability
- **B** — Rocket launcher
- **G** — Select implant
- **H** — Toggle on/off
- **K** — Cyberdeck

## Commands
```
/chrome status
/chrome shop
/chrome buy <id> <certified|shadow>
/chrome stim
/chrome neuro shop|buy <tier>
/chrome detox <clinic|shadow>
/chrome omega
/chrome grant <n>
```

## Features
**Ripperdoc**: Creative items "Summon: Certified Splicer / Shadow Mechanic" (Tools tab) — Right-click on block, then right-click on NPC to open shop.
