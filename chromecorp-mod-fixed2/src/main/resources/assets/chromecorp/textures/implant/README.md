# Текстуры для имплантов ChromeCorp

Эта папка содержит текстуры для 3D моделей кибернетических имплантов.

## Необходимые текстуры

Создайте следующие PNG файлы (рекомендуемый размер: 64x64 или 128x128):

### 1. cyber_eye.png
- Киберглаз (Тактическая Оптика)
- Цвета: красный/синий светящийся, металлический серый
- Стиль: футуристический HUD, светодиоды
- Эффект: должен светиться в темноте

### 2. cyber_arm.png
- Кибер-рука (Гидравлические Поршни)
- Цвета: хромированный металл, черные панели, желтые/оранжевые акценты
- Стиль: механические пластины, гидравлические трубки
- Детали: болты, панели, провода

### 3. mantis_blade.png
- Мантис-клинки (Моно-Лезвия)
- Цвета: серебристый металл с голубым свечением по краям
- Стиль: острое мономолекулярное лезвие с энергетической обводкой
- Эффект: полупрозрачное свечение

### 4. cyber_legs.png
- Кибер-ноги (Пневмо-Сухожилия)
- Цвета: темный металл, красные гидравлические элементы
- Стиль: усиленные суставы, пружинные механизмы
- Детали: поршни, амортизаторы

### 5. armor_plating.png
- Подкожная броня
- Цвета: темно-серый карбон, матовая поверхность
- Стиль: сегментированные панели, защитные пластины
- Паттерн: гексагональная сетка или чешуя

## Референсы

Вдохновляйтесь:
- Cyberpunk 2077 / Cyberpunk: Edgerunners (аниме)
- Deus Ex: Human Revolution
- Ghost in the Shell
- Alita: Battle Angel

## Стиль

- **Цветовая схема**: хром, черный, неоновые акценты (голубой, красный, желтый)
- **Материалы**: металл, карбон, светящиеся элементы
- **Детализация**: провода, болты, панели, светодиоды
- **Эффекты**: свечение (emissive), отражения, полупрозрачность

## Инструменты

Рекомендуемые программы для создания текстур:
- **Blockbench** - для 3D моделей и текстур Minecraft
- **GIMP** / **Paint.NET** - бесплатные редакторы
- **Aseprite** - для пиксель-арта
- **Photoshop** - профессиональный инструмент

## Интеграция

После создания текстур просто поместите их в эту папку.
Игра автоматически загрузит их при запуске.
